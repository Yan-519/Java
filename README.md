# Java Repository

Welcome to this Java repository! This repository contains Java coursework, including lectures, labs, and homework assignments.

## 📁 Repository Structure

```
Java/
├── General/          # General Java resources and utilities
├── HWs/             # Homework assignments
├── Labs/            # Lab assignments
└── Lectures/        # Lecture materials and code examples
```

### Directory Overview

- **General/** - General Java resources, reusable code snippets, and utility classes
- **HWs/** - Homework assignments and solutions for coursework
- **Labs/** - Laboratory exercises and practical programming assignments
- **Lectures/** - Code examples and materials from lectures

## 🛠️ Utility Scripts

This repository includes batch scripts for streamlined Git operations:

- **Pull.bat** - Pulls the latest changes from the remote repository
- **Push.bat** - Pushes local commits to the remote repository
- **local commit.bat** - Creates a local commit with your changes

### Running the Scripts

On Windows, you can execute these batch files directly:

```bash
Pull.bat           # Update your local repository
local commit.bat   # Commit local changes
Push.bat          # Push changes to remote
```

## 📝 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Yan-519/Java.git
   cd Java
   ```

2. **Navigate to the section you need**
   - For coursework: Check the **Lectures/** folder
   - For assignments: Look in **Labs/** or **HWs/** folders
   - For utilities: Browse the **General/** folder

3. **Run Java files**
   ```bash
   javac FileName.java
   java FileName
   ```

## 📚 Contents

This repository is organized by learning material type, making it easy to navigate between different types of Java coursework and practice.
